# Business Entity Resolution using Hybrid Blocking and Machine Learning

## Problem Statement
The goal is to correctly match a set of clean reference business entities (Source 1) to two noisy datasets (Source 2, Source 3), identifying multiple potential matches, one match, or no matches at all per entity.

## Architecture
Data
 ↓
Normalization (Name, Address)
 ↓
Blocking (Exact, Tokens, TF-IDF nearest neighbors)
 ↓
Candidate generation
 ↓
Similarity features (Levenshtein, Jaccard, count diffs)
 ↓
ML classifier (Random Forest)
 ↓
Threshold optimization (Grid search for best F0.5)
 ↓
Final matches

## Output
- `output/matching_results.tsv`: Contains final matches.
- `output/candidate_pairs.tsv`: Contains all pairs generated by blocking.

## Evaluation
Evaluates using a macro entity-level F0.5 score, giving 0 for incorrect matches on singletons and 1 for correctly identifying empty matches.

## Limitations
- Noisy data and missing values can affect similarity features.
- Blocking relies on character overlap which might miss complete aliases.
